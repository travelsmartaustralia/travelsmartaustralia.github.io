PUBLISH ON GITHUB PAGES
1. Sign in to GitHub as godcretus.
2. Open https://github.com/godcretus/godcretus.github.io
3. If the repository does not exist yet, create a PUBLIC repository with that exact name.
4. Extract this ZIP on your computer.
5. Open the extracted travel-smart-australia-advanced folder.
6. Upload every file INSIDE the folder into the ROOT of the repository.
   Important: index.html, styles.css and app.js must be at the repository root.
7. If GitHub asks whether to replace existing files, confirm replacement.
8. Commit the changes to the main branch.
9. Open repository Settings > Pages. Choose Deploy from a branch, branch main, folder /(root), then Save.
10. Wait for the deployment to finish and visit https://godcretus.github.io/

IMPORTANT
- This is a static website. The trip planner and budget tool run in the visitor's browser; they do not save data or contact an external service.
- The checklist selections are not saved after leaving or refreshing the page.
- There is no live booking search, payment system, newsletter signup, account system or live currency conversion.
- Do not add Booking.com logos, tracking links or claims of partnership until approved and provided with authorised affiliate links/assets.
- GitHub Pages hosting is free for public repositories on GitHub Free. Repository source files are public. Never upload passwords or private documents.
- The privacy and disclosure pages are starter templates. Update them if adding analytics, forms, cookies, ads or affiliate tracking.
